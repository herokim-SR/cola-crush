# 콜라 박살내기 🥤🔨

식탁 위 콜라캔을 망치로 쳐서 납작하게 찌그러뜨리는 어린이용 웹 게임입니다.

## 플레이하기
- 바로 하기: https://herokim-sr.github.io/cola-crush/
- 태블릿/폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼, 인터넷 없이도 할 수 있어요.

## 하는 방법
- **톡** 누르면 망치로 한 번 쳐요.
- **꾹** 누르고 있으면 힘이 모이고, 손을 떼면 더 세게 쳐요.
- 캔 **윗부분(노란 띠)** 을 치면 잘 찌그러지고, 옆이나 가운데는 조금만 찌그러져요.
- 캔이 납작해지면 10점과 코인 10개! 50점이면 "오예!"
- 코인으로 ⏸ 쉬기 → 🎁 상점에서 새 망치와 망치 무늬를 살 수 있어요.
- 캔은 점점 단단해져요(빨강 → 주황 → 검정, 색으로 알 수 있어요).

## 안전
광고·링크·채팅·입력칸·외부 통신이 없습니다. 그림과 소리는 모두 코드로 직접 만들었고, 기록(최고 점수·코인·소리 설정·산 아이템)은 기기 안에만 저장됩니다.
